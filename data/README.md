# Data

This directory contains the original, fictional Dutch help corpus and evaluation labels.

- `pages.json` contains 40 fictional help pages.
- `queries.json` contains 25 Dutch queries with typed, graded relevance judgments.
- `enrichment_cache.json` contains validated summaries and metadata for every page.

The future corpus must contain no real bank names, branding, copied text, customer records,
or personal identifiers. Keep evaluation queries and relevance labels separate from page content.
